誤爆ごめん｜プライバシーポリシー

「誤爆ごめん」は、Twitch、YouTube Live、ニコニコ生放送、ツイキャス、Kick のライブチャットで、意図しない入力・貼り付け・送信を防ぐ Chrome 拡張機能です。

端末内で処理する情報

  • 拡張機能は、対応ページのチャット入力欄、送信ボタン、ページの状態を確認し、ロックや再ロックを適用します。
  • 貼り付け確認がオンのときは、ユーザーが保護対象の入力欄に貼り付けを行った際に、そのテキストを一時的にブラウザー内で扱います。同意した場合だけ入力欄に挿入します。貼り付け内容を履歴として保存しません。
  • 各サイトの有効・無効、解除時の確認、再ロックの条件と時間、送信キーの保護、表示言語などの設定は、そのブラウザープロファイルの拡張機能のローカルストレージに保存します。

外部への送信・共有

拡張機能は、チャットの下書き、貼り付け内容、閲覧履歴、設定を開発者のサーバーに送信せず、広告やアクセス解析を行いません。これらの情報を販売したり第三者へ提供したりしません。ユーザーがチャットを送信した場合は、配信サービスの通常の送信機能と、そのサービスのプライバシーポリシーが適用されます。

拡張機能が扱う情報はチャットの誤送信防止のために使用し、Chrome ウェブストアのユーザーデータに関するポリシーと限定使用の要件に従います。ローカル設定は拡張機能をアンインストールすると消去されます。

Privacy policy — Gobaku Gomen

Gobaku Gomen helps prevent accidental typing, pasting and sending in live chat on Twitch, YouTube Live, Niconico Live, TwitCasting, and Kick.

The extension inspects chat inputs, send controls and page state on supported pages to apply the lock. When paste confirmation is enabled, it temporarily handles the text from a paste initiated by the user in a protected chat field, and inserts it only after approval. It keeps no clipboard history. Site toggles, confirmation and relock settings, send-key protection, and language preferences are stored locally in the browser profile. These settings are removed when the extension is uninstalled.

The extension does not send drafts, pasted text, browsing history or preferences to developer servers. It does not use ads or analytics and does not sell or share this data. A chat message the user chooses to send is handled by the livestream service under its own privacy policy.

The extension uses the information it handles only to prevent accidental chat submissions and complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. For privacy questions, use the developer contact listed in the Chrome Web Store.
